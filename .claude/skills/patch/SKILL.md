# /patch — 이 저장소에서 코드를 고치는 법

## 🔴 첫째 규칙 — 새 코드 조각은 «파일»로 짓는다

`sed`·`node -e`·heredoc 으로 코드를 지으면 **백슬래시·달러·백틱이 셸에서 깎인다.**
깎인 채로도 **검사가 통과한다** — 화면에서만 이상해지고, 그때는 어디서 깎였는지 안 보인다.
이 저장소에서 실제로 여러 번 겪은 사고다(`정규식 \d` 가 `d` 로 · 템플릿 `${}` 가 통째로 · NUL 이스케이프가 진짜 NUL 바이트로).

**그래서 이렇게 한다** — 조각은 `.txt` 파일로, 끼우는 것은 `tools/splice.mjs` 로.

```js
// 임시 폴더에 patch.mjs 를 두고, 새 코드는 옆에 frag-*.txt 로 짓는다
// ⚠ 윈도에서 import 경로는 file:/// 여야 한다 — 그냥 C:/… 로 적으면 ERR_UNSUPPORTED_ESM_URL_SCHEME.
//   경로의 빈칸은 %20 으로. (읽는 경로는 그냥 C:/… 로 적어도 된다 — import 만 까다롭다.)
import { 열기 } from 'file:///C:/Users/hahyun/Desktop/claude%20work/tools/splice.mjs';
const F = 열기('C:/Users/hahyun/Desktop/claude work/index.html');
F.사이('function 어쩌구(', '\n/* 다음 함수 주석 */', F.조각('frag-어쩌구'));
F.한번('const 값 = 1;', 'const 값 = 2;');
F.저장();          //  OK index.html 2109982 → 2110441자 (+459)
```

- `한번(닻, 새것)` — 닻이 **딱 하나**여야 한다. 둘이면 멈춘다(어느 쪽을 고쳤는지 모를 일은 안 한다).
- `사이(앞, 뒤, 새것)` — 앞 닻(포함)부터 뒤 닻(제외)까지 통째로.
- `조각(이름)` — 패치 스크립트 **옆**의 `<이름>.txt` 를 한 글자도 안 건드리고 읽는다.
- `node tools/splice.mjs` — 이 도구 자체의 검사(5개)가 돈다.

⚠ Write/Edit 도구로 직접 고치는 것도 좋다 — 셸을 안 지나므로 안전하다.
  줄 수가 많거나 여러 자리를 한꺼번에 바꿀 때만 splice 를 쓴다.

## 🔴 둘째 규칙 — 고쳤으면 «덫»을 놔 본다

검사가 초록인 것과 **검사가 그 자리를 보고 있는 것**은 다른 말이다.
새로 만든 검사는 **반드시 한 번 일부러 망가뜨려** 무는지 본다.

```bash
cp index.html "$TMP/idx.bak"
# 고친 줄 하나를 되돌린다 → 검사가 빨개져야 한다
node tools/그-검사.mjs
cp "$TMP/idx.bak" index.html     # 되돌린다
```

덫이 안 물면 그 검사는 **아무것도 안 지키고 있는 것**이다. 닻을 다시 잡는다.

## 검사

```bash
node tools/check-all.mjs      # 전부. 「✓ 전부 초록 · N개」가 나와야 한다
node tools/<하나>-test.mjs    # 고친 자리 하나만 빨리
```

- 검사는 `index.html` 에서 함수를 **글자로 떠다** 돌린다(`lift('함수이름')`).
  그래서 **함수 이름을 바꾸거나 인자를 늘리면 그 검사부터 터진다** — 터진 검사의 닻을 같이 옮긴다.
- 새 함수에 기댄 검사는 `lift` 목록에 그 이름을 **추가**해야 한다(안 하면 `ReferenceError`).
- 검사는 **코드를 봐야지 주석을 보면 안 된다** — 내가 쓴 주석에 그 이름이 나와서 헛물켠 적이 있다.

## 화면을 바꿨으면 눈으로 본다

```bash
node tools/serve.js            # http://127.0.0.1:8777
node tools/shots.mjs <화면>    # 폭마다 스크린샷 (Playwright)
```

- 사용자의 주력 판은 **CSS 폭 864px**(브라우저 125% 확대)다. 1280 에서만 보고 끝내면 안 된다.
- 폰은 390. 「어색하다」류 신고는 **코드로 못 찾는다** — 반드시 열어서 본다.
