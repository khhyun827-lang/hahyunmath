# 복습테스트 문항 풀 — SCENE 1 (기본 유형)

교재에 실린 46문항 각각에 대해, **같은 학습 요소를 묻지만 압축 과정에서 뺀 문항**을 모았다.
복습테스트는 여기서 골라 내면 «배운 것과 같은 것을 묻되 문제는 다른» 시험지가 된다.

- **원 문항** = 교재에 실린 것 (학생이 이미 푼 것)
- **복습 후보** = 뺀 문항. 「사유」가 곧 «어떤 점에서 같은가»이다
