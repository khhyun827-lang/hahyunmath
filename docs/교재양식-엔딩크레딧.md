## 사용자가 정한 규칙
- `<보기>` → `[보기]` (본문·해설 모두)
- 한 단에 SCENE1 3문제(길면 2) · SCENE2 2문제 · SCENE3 1문제
- 객관식 틀: **1행** = 숫자 하나·둘 길이 / **2행** = 그보다 길 때(2√3 처럼 루트가 들면 2행) /
  2행이 모자라면 **3행** / 줄글 선지·3행도 모자라면 **5행**. ㄱㄴㄷ 조합 선지는 2행
- 그림: 문제 글과 표·조건·선지 «사이», 가운데, 글자처럼 취급. 선지 뒤에 있던 그림도 앞으로
- 미주: 예시처럼 문항 표 안의 그 자리, 흰 글씨
- 출처: 흰 글씨 + 빨간 형광펜, 표 안에는 번호 없이 `[교재명]`
  (출처는 미주 첫 줄의 «숨은 설명»에 있다 — 숨은 설명은 그대로 둔다)
  고쟁이→`[고쟁이]` · 유형반복R→`[유형반복R]` · 올림포스유형편→`[올유]` · 절대등급→`[절대등급]`
- 표지·차례는 빼고 본문만 · 유형 번호는 1부터 다시(빠진 번호·번호 없는 제목도 차례대로)
- 문항은 SCENE별로 모은다 — SCENE1 전 유형 → SCENE2 전 유형 → SCENE3
- 「오른쪽 그림」 → 「다음 그림」
- SCENE2 머리는 틀의 SCENE2 전용 스타일
- **바탕쪽** — 단원 첫 쪽만 다른 양식, 그 뒤는 홀수·짝수 쪽 양식. 그래서 첫 구역은 첫 두 쪽뿐이고 쪽 번호는 2(짝수)에서 시작
- **SCENE 머리가 있는 쪽만** 시작을 내린다. 머리 없는 쪽은 위에서 바로 시작
- **문항 표는 늘리지 않는다**(나중에 문제를 고칠 수 있어서) — 왼쪽·오른쪽 단 번호 줄은 «표 사이 간격»으로 맞춘다

## 쓰는 법
```
mkdir in work && cp 원고.hwpx in/ && (cd work && unzip -q ../in/원고.hwpx)   # 틀도 같은 식으로 tmpl/
python3 -I tools/textbook-form/build.py tmpl work out 10 무리함수
python3 -I tools/textbook-form/audit.py work out      # 본문·미주 대조 — «다른 것 0» 이어야
python3 -I tools/textbook-form/validate.py out        # 참조·id 겹침·미주 차례
python3 -I tools/textbook-form/sim.py out             # 좌우 단 줄 어긋남·단 끝
python3 tools/textbook-form/pack.py out "[2026][엔딩크레딧][1-2기말]10.무리함수_양식적용.hwpx"
```
살펴보기: `dump.py section0.xml`(문단) · `notes.py section0.xml`(미주·숨은 설명) · `cp.py header.xml`(글자 모양).
`build-report.json`(나갈 폴더 옆)에 문항마다 출처·틀·어림 높이·자리가 남는다.

## 원고가 이렇게 생겼다고 본다 (다른 꼴이면 build.py 3절을 고친다)
- 유형 머리 = 글자 모양 3(13pt 굵게) 문단, `01, 제목` · `4. 제목` · 번호 없는 제목 모두
- SCENE 표지 = `SCENE 1` 만 든 문단(글자 모양 무관) · SCENE3 은 `scene3` 머리 문단이거나 미주 문단 맨 앞의 `SCENE3`+줄바꿈
- 문항 = 미주가 든 문단부터 다음 미주 전까지 · 선지 = `①` 로 시작하는 문단부터
- 보기 = «보기» 글이 든 상자(rect) 또는 3행 표 · 그 밖의 상자 = 조건 상자
- 그림 선지 표(①~⑤ + 그림) = 원래 표를 단 폭(22228)에 맞게 줄여 옮긴다 — 양식에 그림 선지 틀이 없다
- 미주 안 글자 모양 0·2 → 틀 0 · 1([정답]) → 틀 31 (`CHAR_FIXED`) — 원고 머리가 바뀌면 `cp.py` 로 다시 볼 것

## 함정
- 한글은 **개체 id 가 겹치면 죽는다** — 도형·수식 id·instid 를 새로 매긴다(validate 가 센다)
- 표 칸에는 문단이 하나 이상 있어야 한다 · mimetype 은 zip 맨 앞에 압축 없이(pack.py)
- 칸 찾기는 «바로 아래 칸만» — 안쪽 선지 표 칸을 집으면 엉뚱한 칸을 덮는다
- 그림 설명문의 사람 이름(장은영)은 지운다
- 줄 맞춤은 문항 높이 «어림»으로 한다(한글이 다시 배치한다) — 긴 문항에서 조금 어긋날 수 있다

  SCENE1 문항 사이 빈 줄 하나(1600) · SCENE2 다섯 줄(8000)
